# M2 用户验收指南

> 用途：验收 M2 本地核心原型（挂载/索引/搜索/排除/打开位置）。应用当前已在后台运行，或按下方方式重启。

## 启动方式
- 端口 8371 已在后台运行（lead 托管）；若停止，可在项目根目录执行：
- `python run.py --port 8371`（Python 需装 requirements.txt 依赖）
- 访问 http://127.0.0.1:8371，首次弹窗输入 token（在 `~/.chiselwall/config.json` 的 api_token 字段）

## 验收要点
1. 随手记 → 添加目录（建议先选小目录、无敏感内容）→ 观察索引进度与统计；
2. 搜索一个确定存在的词/短语：命中片段带黄色高亮 + 出处；
3. 排除：对文件/目录右键排除（或规则面板加 glob），再搜应 0 命中；
4. 打开所在位置 / 直接打开：文件管理器定位 / 默认程序只读打开；
5. 失败列表：加密 PDF、扫描件应进失败列表且不影响其他文件；
6. 资源体感：索引期间电脑应流畅（进程低优先级 + 空闲调度）。

## 已知说明
- 首次搜索加载 jieba 词典约 0.3 秒（一次性）；
- UI 为 M2 最小雏形（Vue CDN 版），外观与完整侧边栏在 M3 交付；
- 验收反馈直接回复 lead，整理后作为 M3 输入。
