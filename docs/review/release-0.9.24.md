# 凿壁 ChiselWall v0.9.24

Windows / Linux x86_64 免安装包。

## 本版修复

- 修复「远端搜索结果有 1 条，但 AI 说没有找到资料」：
  - 本地笔记会通过 enrich_local_context 拿到完整文档/邻接块；
  - 远端节点之前只回传约 150 字 snippet，设备 2 的 AI 上下文不足；
  - 现在远端 answer 会附带命中块及相邻块 ai_text（最多约 4KB/条）；
  - 没有 strong 命中时，AI 回退使用最多 8 条 weak 结果，并在上下文标注「弱相关」；
  - 完全没有可用上下文时，直接返回明确提示，不再让模型凭空回答。
- 远端结果在随手问里显示「弱相关」标记；只有弱结果时给出提示。
- AI 回答记录 strong/weak/上下文长度，便于设备端排查。
