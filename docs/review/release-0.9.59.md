# v0.9.59 发布说明

日期：2026-11-16

## 核心变化

- 无 AI / QueryPlan 未就绪时直接原文检索，不再等待计划超时。
- 随手问每条用户消息显示“本轮检索词”；有 plan 显示 plan.expression，否则显示原文。
- 随手问会话卡片压缩，改名/删除收进“···”菜单。
- 右侧搜索结果卡显示“卡片 #n”。
- 引用徽标显示对应卡片编号；点击引用可滚动到右侧卡片并高亮。
- 回答正文中的 [eN]/[n] 可点击跳转到对应结果卡。
- 随手记/随手问顶部标题字号调小。

## 验证

- 全量 357 项测试通过。
- 浏览器实测：会话菜单、卡片编号、引用徽标跳转、正文 [eN] 跳转。
