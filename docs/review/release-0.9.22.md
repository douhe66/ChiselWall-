# 凿壁 ChiselWall v0.9.22

Windows / Linux x86_64 免安装包。

## 本版更新

### 共享前敏感词检查（L0/L1）
- 25 条内置规则：凭证、身份证/银行卡/手机号、合同/客户/薪酬/法务、路径关键词；
- 自定义敏感词、屏蔽规则；内置规则不可删除，只能屏蔽；
- 索引完成自动扫描；启动补扫存量；规则变更后台重扫；
- 仅共享、启用挂载、未忽略的文档参与待确认；仅本机/隐藏不亮红点；
- 文档级命中/确认指纹，新增敏感词会重新提醒；
- 6px 红点、顶部共享前检查条、检查抽屉、设置规则管理；
- 分组/挂载可忽略提醒（跳过扫描，恢复时补扫）；
- 凭证/PII 摘要掩码，只在本机保存。

### UI
- 确认/设为仅本机后回到敏感列表，不关闭抽屉；
- 移除独立“共享前请确认”横幅，说明合并到检查抽屉；
- 新增 favicon，浏览器标签页显示凿壁图标；
- 文档列表最多展示 500 条，避免红点文档被截断。
