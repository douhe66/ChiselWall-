# M6 部署与邀请手册（relay + 提问组）

> 适用版本 v0.6.3+。中心只路由、不存知识。

## 1. 部署 relay（管理员，一次）

```json
// relay.json（与 relay 启动参数 --config 指向同一文件）
{
  "users": { "张三": "token-zhang", "李四": "token-li" },
  "rate": 0.2,
  "burst": 2
}
```

```bash
PYTHONPATH=src python -m relay.server --config relay.json --host 0.0.0.0 --port 18760
```

- 在线表与组注册表都在内存；组注册表持久化在 `relay-groups.json`（与 relay.json 同目录）。
- 用户表修改后**热加载**：同事下一次连接自动生效，无需重启 relay。

## 2. 发邀请（管理员，每位同事一次）

```bash
python -m relay.admin invite 张三 --group 数据库组 --url ws://10.0.0.5:18760/ws
```

输出一段邀请文本（昵称 / relay 地址 / token / 建议组）。把它发给同事（微信、邮件都行）。

- `python -m relay.admin list`：查看已有用户（token 掩码）
- `python -m relay.admin revoke 张三`：吊销 token（对方断线后无法再连）
- `--group` 可多次；组会自动登记到组注册表（无描述，之后可在节点设置页补描述？——当前未支持编辑描述，重建即可）

## 3. 同事侧（每位同事）

1. 打开凿壁 → 设置 → Relay 连接；
2. 粘贴邀请里的地址 / 昵称 / token；
3. 在「提问组」里勾选要加入的组（可随时退出/加入）；
4. 点「保存并连接」，右上显示已连接即可。

## 4. 提问组（自由建组）

- 任意同事可在设置页「建组」：填组名 + **描述**（描述所有人可见）；
- 所有人能看到全部组及在线人数；
- 勾选 = 加入，取消 = 退出；默认加入「全员组」（所有在线节点）；
- 提问时默认只问自己加入的组，可在提问页改选其它组。

## 5. 常见问题

- **连不上**：检查地址端口（默认 18760）、防火墙、token 是否被吊销；设置页保存后会自动重连。
- **组里没人**：组是广播域，不要求有人才能建；加入后即可在提问页选它。
- **安全**：token 即身份，不要公开发送；泄露立刻 `revoke` 并重新 `invite`。
