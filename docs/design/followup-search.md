# 随手问追问：重新检索与无结果回退（v0.9.9）

## 问题

旧追问只读取上一轮 user payload 的 aggregated；如果上一轮没有命中，直接报错，
而且无法查询一个不在上一轮结果里的新问题。

## 行为

- 默认追问：沿用上一轮结果 + 对话历史，不广播（低打扰）。
- 勾选「重新检索」：把当前输入作为新问题广播，保留会话历史；新结果用于本轮 AI。
- 上一轮没有可用结果：自动走新检索，不再报错。
- 新检索仍使用提问组、发送前查询计划、relay/远端流程。

## 实现

- 前端「重新检索」复选框；forceSearch = 首问 / 勾选 / 最近一轮无 hits。
- 新检索复用 ask_session_ask + 轮询 + complete + AI 综合流程。
- 后端 latest-user 只取最近一轮 user turn，不再回溯到更早的有结果轮次；
  最近一轮无结果时返回 needs_search，提示重新检索。

## 边界

- 没有做“自动判断这个问题是否超出上一轮结果”的语义路由；需要用户勾选重新检索。
- 重新检索会广播给同事，默认不勾选以避免每轮打扰。
- 追问历史仍保留，AI 可以看到前几轮问答。
