# UI v2：深色科技感 / 信息密度 / 可操作性

> v0.8.4。目标：在保留全部功能的前提下，把界面从"表单堆叠"升级为面向检索与协作的工作台。

## 调研结论

参考 2025–2026 主流控制台与 AI 产品（Linear、Vercel Geist、shadcn/ui、Raycast 类命令面板、AI copilot 模式）的共识：

- **中性深色分层**，不用纯黑、不用大面积发光：背景 → 面板 → 浮层逐级提亮；
- **左侧图标导航** + 清晰 active 状态；不要横向 tab 堆叠；
- **Inter / 系统无衬线 + 等宽字体** 处理 ID、路径、耗时、快捷键；
- **4px 间距网格**，面板 16–20px 内边距，卡片 hover 只做边框/背景变化，不缩放；
- **语义色**：成功=青绿、警告=琥珀、错误=珊瑚、信息=靛蓝；状态点 + 文本，不只靠颜色；
- **内容密度优先**：KPI 用数字卡片，列表用行高 40–44px，结果片段限高内部滚动；
- **命令面板/快捷键**：Ctrl/⌘+K 聚焦搜索；
- **微交互**：150–250ms ease，页面淡入、hover、toast；尊重 reduced-motion。

## 设计令牌

- 背景 `#070a10`，面板 `#0e1521` / `#121b29`，边框 `rgba(148,163,184,.13)`
- 主色 `#5eead4`（青绿），次色 `#818cf8`（靛蓝），错误 `#fb7185`
- 字体：Inter / SF Pro / PingFang SC；等宽：JetBrains Mono / Cascadia Code
- 圆角：面板 14px，控件 8–9px，胶囊 99px
- 主题：深色默认，浅色可切换并记忆在 localStorage

## 布局

- **全局 rail**：品牌、随手记、随手问、设置；底部 Relay 状态 + 主题切换 + 版本；
- **随手记**：页头 → 5 个 KPI → 命令式搜索条 → 工作区卡片（分组/挂载/排除/文档）；
- **随手问**：会话列表 / 对话 / 搜索结果三栏；结果栏可拖动 260–760px，会话/回答/结果各自内部滚动；
- **设置**：左侧 sticky 分区导航 + 右侧单列宽表单，避免长页面迷路。

## 交互

- `Ctrl/⌘ + K` 聚焦本机搜索；
- 搜索结果片段默认限高，展开后完整显示；
- 随手问首问广播、追问不重播；AI 综合可勾选自动或手动；
- 空状态提供明确下一步（新建会话 / 输入问题）；
- 全部按钮、输入、导航有 focus-visible 环；状态点带在线光晕；
- 移动端：rail 变横向、三栏变单栏、结果栏落到对话下方。

## 约束

- 仍为 Vue3 全局构建 + 原生 HTML/CSS/JS，无打包器；离线可用；
- 不引入外部字体/CDN，避免内网依赖；
- 后端 API、数据结构、会话语义不变。
