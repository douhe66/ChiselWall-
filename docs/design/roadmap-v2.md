## M7 验收口径（先定，避免做完扯皮）

- **召回**：构造 20 条"同义/概念"测试问题（如"文件锁怎么加"），混合检索命中率 ≥ 纯 BM25 +20pp；
- **性能**：单节点 2 万块向量，查询 P50≤50ms / P95≤100ms（含查询向量化）；建索引单线程 ≤5 分钟/2 万块；
- **资源**：开启向量后空闲 RSS ≤300MB（放开红线，但需在设置页标注）、可随时关闭并回退；
- **部署**：优先走内网 `/embeddings`（零本地安装）；本地 ONNX 模型作为离线备选（包体 +100MB 左右）。

## M8 验收口径

- 对任意一条随手问结果点「追问」→ 携带上一轮 qid + 聚合片段 + AI 回答作为上下文，回答能引用上一轮内容；
- 「AI 会话」入口：会话列表、新建/切换/重命名/删除；每个会话独立上下文；与随手问共享检索与 LLM 能力；
- 多轮上下文有长度预算（如最近 3 轮 + 本轮检索），超预算自动摘要/截断。
